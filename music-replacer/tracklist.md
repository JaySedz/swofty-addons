## Notes for a replacement addon

- 56 of the 70 streamed files also keep their opening inside music.bnk (Wwise prefetch). Replacing only the .wem would play the original song's opening first, so music.bnk has to be rewritten with the new song's opening (or without the prefetch) too.
- The 3 theme pieces live entirely inside music.bnk.
- music.bnk holds only audio (an index plus data, no logic), so rebuilding it with replaced entries is simple. metadata.bnk records each track's length, which may need updating for a song of a different length.
- Audio format: Wwise Opus (codec 0x3041), 48 kHz stereo.
